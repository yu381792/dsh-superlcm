# 0.5.25 升级说明

修复旧 DSH 日志出现编号重叠和多段交错写入后无法归档的问题。使用 DSH 官方旧格式解码器逐行校验，将全部记录按文件中的实际顺序归档，原事件编号和内容保持不变，压缩源文件的完整字节同时保存。

## 读取恢复记录

`lcm_read` 和查询接口返回 `sequenceMode: physical-order`。分页 `offset` 和返回的 `seq` 表示归档顺序位置，`sourceSeq` 是原日志编号，`sourceRow` 是原文件行号。正文仍为保留原编号的原事件。相同原编号的冲突记录会全部返回。`lcm_outline` 显示恢复说明，此类旧日志用于原文检索，跳过摘要生成和压缩树重建。

恢复读取保持容量上限：压缩源文件 128 MiB，解码内容 256 MiB，单行引用展开及恢复事件各不超过一百万条。超限明确报错并保留原文件。

只对宿主无法读取、尚未生成当前格式文件的历史来源进行恢复。坏压缩帧、坏行、来源变化、已有原文冲突仍会报告真实失败。原 DSH 文件保持原样，恢复归档不会使损坏的宿主会话变成可继续运行的会话。

设置、模型与压缩参数保持不变。运行中的宿主需重新加载插件后生效。GitHub 自动测试保持关闭，本版执行本地测试和独立审查。
