# 0.5.31 升级说明

修复 DSH 接管压缩时反复显示“后台摘要尚未就绪”或“当前轮原文或后台摘要仍占用过多空间”的一种卡住情况。

已完成的摘要前缀可能因后续分块或合并失败而一直不能提交。在紧急阈值下，插件现在会核对已完成前缀、工具边界、当前用户输入、模型和设置身份；只有预计替换后低于正常压缩阈值，才提交该前缀。后续尚未摘要的原文继续留在上下文中。普通后台准备仍不提前替换上下文。

已保存的单根摘要恢复时不再向 DSH 原生日志写入缺失的供应商流数据。在途后继摘要被替代后，其迟到结果不能恢复过期草稿。

使用正常 DSH 插件升级命令安装新包，并重新启动对应宿主。原文、已提交摘要和现有模型及压缩设置保留。升级后可在原会话重试原请求。

验证使用真实 DSH 服务和离线合成模型响应，包括持久化恢复、失败后提交、严格 JSON、树重建、用户输入保护、模型变化和迟到结果。没有付费模型测试；跨平台真实机器和真实浏览器验证范围见 [VALIDATION.md](VALIDATION.md)。
