# 0.5.33 升级说明

本版修复一种反复出现的“当前轮原文或后台摘要仍占用过多空间”：系统提示词和工具占用较大时，旧算法为追求固定的压后目标，只给摘要剩下约 1K 空间。已有摘要连原文导航标记都放不下，便反复合并同一份摘要，无法推进后面的历史原文。

新版把无法压缩的系统及工具成本加到正常摘要预算和近期原文预算之外。用户设置的压缩比例、摘要分块和模型不变，压缩后仍必须低于正常替换门槛。真正无法容纳固定提示词、近期原文和摘要的配置会明确拒绝，不发送超窗口请求。

使用 DSH 官方插件命令更新所用启动配置：

```sh
dsh plugin --profile paseo add ./SuperLcm-0.5.33.tgz --offline
```

其他启动配置将 `paseo` 换成对应名称。插件包中没有本机绝对路径。模型和设置文件应在升级前后保持一致。已运行的会话重新加载底层进程后才会使用新算法，可以继续原对话。升级保留原文、已有摘要和持久草稿。

专项验证使用真实宿主和本地假模型，覆盖大固定提示词、已有草稿恢复、剩余原文推进、当前输入保留和重复检查不重复提交。真实摘要的语义质量仍取决于所选模型。
