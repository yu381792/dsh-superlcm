# DSH 摘要重试与错误提示修复

独立插件已有串行摘要调度。本次针对真实模型调用路径修复每次质量重试独立超时，保持整个任务的取消、设置版本与数据库写入归属检查。

没有返回正文和正文传输中断现在有不同的安全错误原因。仍须收到真实的成功终止事件才可保存摘要或替换上下文。出错时保留完整原文，不把部分输出当成完整摘要。

共享摘要提示词区分请求目标长度与实际验收上限，与完整版保持一致。用户现有模型、分块设置、压缩比例和接管选择均沿用。

永久测试新增了真实 DSH ArchiveService 假模型路径：质量重试获得不同请求信号、摘要前缀保持一致、无正文和截断分别拒绝、原文及会话表面保持不变。发布检查使用隔离环境和合成数据，包含官方安装与旧版更新；不调用付费模型。

完整版的多会话子进程队列与后台页面修复见 [SuperLcm 专项说明](https://github.com/yu381792/superlcm/blob/main/docs/SUMMARY-JOBS-0.5.27.md)。两版共享语义规则，分别适配各自宿主。
