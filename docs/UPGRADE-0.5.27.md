# 摘要语言和指令隔离修复

完整版 0.5.24 与 DSH 独立版 0.5.27 同步修复 SuperLcm issue #5 和 #6。

摘要的正文与各节标题跟随用户消息的语言。判定只读取用户正文，排除助手回复、工具结果、系统提醒、注入内容与压缩检查点。当前段没有足够用户文字时回溯真实用户消息；合并层按会话用户文字确定语言，不继承子摘要的错误语言。中文、日文、韩文和可识别的拉丁语种使用明确要求；其他语言保留“用户自己使用的语言”要求，不把文字体系猜成特定语言。代码、路径与原文引语保持原样。

普通摘要、合并摘要和两种修复提示词都在原文后重申摘要任务。源文档中的指令只作为历史事实记录，不执行、不续写、不回答。输出必须直接以 Markdown 节标题开头。OpenAI 使用独立 system 消息，Anthropic 使用顶层 system。

所有自动和人工提交的摘要入口均检查语言与标题。API 与 DSH 模型流遇到质量失败时最多补试一次；持续失败保留原文并返回明确错误，不存入导航树。DSH 主备模型共享质量补试次数。DSH 手动压缩新增的历史提醒放在正文后，跟随摘要语言，最终正文再次检查。新政策令升级前尚未提交的 DSH 草稿失效，避免继续使用旧提示词生成的草稿。已存原文、节点、模型与用户设置保留，不自动付费重写旧摘要。

完整版额外修复了全量测试发现的并发索引竞争：读取索引游标、写归档副本和添加记录在同一写锁内；遇到坏行仍保留已完成前缀，提交失败会释放事务。

验证只用合成对话、假模型和本机运行时，包含工具输出混入、长指令文档、语言错配、错误节标题、正文占比、元消息分页回退、原文不变、有界重试、合并层语言与 DSH 真实接管路径。独立审查使用额外探针复核。真实 Windows、Linux GitHub 自动测试按用户要求保持关闭，不能将本机验证描述为这些平台实测。
