# 0.5.24 旧日志原文归档

0.5.23 明确显示旧日志无法由宿主升级。本版继续解决原文保存：当 DSH 拒绝迁移旧会话时，用宿主公布的旧格式解码器直接读取历史文件，不把异常历史恢复成活动上下文。

按帧严格读取 Zstandard 压缩文件，完整展开打包事件，保留原始编号和内容。压缩物理字节及其 SHA-256 一并存入数据库。源文件只读，不补对话结束事件、不修改原日志。错误帧、错误行、序号缺口、来源身份冲突和当前格式文件存在时拒绝回读旧来源。

旧格式回读只用于历史原文查询，不自动生成摘要，不重建压缩节点。旧会话后来变成当前格式时拒绝混合两种记录，保留已归档来源并明确提示核对。普通会话的摘要和可选接管保持原设置。

## 验证

58 项现行测试通过。两条实际旧会话在隔离回放中归档 60,545 条事件；逐条内容一致，压缩物理字节一致。原始文件保留。使用官方安装器在 macOS 实测从 0.5.21 更新，设置、数据库、模型目录和原生压缩保留。

使用 DSH 自带插件管理更新，或运行：

```sh
dsh plugin --profile web add ./SuperLcm-0.5.24.tgz
```

Windows/Linux 本轮未实机执行；读取采用 Node.js 与 DSH 官方解码器，不依赖本机命令、用户目录或另一 Web 服务。GitHub Actions 保持关闭。
