# 0.5.28 升级

本版修复主动审查发现的两条 DSH 路径：接管压缩曾接受没有结束标记的模型流；后台归档曾漏认真实工具结果的 `message.toolCallId`，把完整工具组当作未完成，导致后续摘要停住。

摘要必须以真实 `stop` 事件结束。截断、错误、取消、未知结束原因、重复结束、结束后输出或工具调用均拒绝；不能保存为完整摘要，也不能替换原上下文。不合格模型流不会自动作为语言修正再付费重试。旧策略下尚未提交的准备草稿失效，原文、已提交摘要、精确召回和配置保留。

```sh
dsh plugin --profile web add ./SuperLcm-0.5.28.tgz
```

其他 profile 用各自名称。现有宿主须重新加载或重启后使用新代码；安装版本与当前运行版本分开核实。压缩仍是可选设置，升级不改变摘要模型、分块、比例或接管开关。

发布者在升级前运行 `npm run verify:release`，包含完整回归、真实隔离宿主安装升级与实际 npm 包引用检查。测试用本地假模型，不消耗摘要额度。故障回归覆盖异常流不得存储或替换、完整工具组可继续摘要，以及迟到输出不能恢复旧设置。

本轮实测 macOS 与 DSH 0.2.1-alpha.1。GitHub Actions 按用户要求保持关闭，没有本轮 Windows/Linux 实机结果；不宣称所有环境不存在 BUG。完整版共用模型流修复同步发布为 0.5.25；它还修复独有的 CLI、分段、文本导入语言和失败退避问题。
