# 0.5.29 升级

本版同步完整版 SuperLcm 的摘要提示词修复。公共规则和原文放在前面，分块范围、语言、层级和长度放在后面。质量重试保留相同的规则与原文前缀，摘要任务提醒仍位于最后，避免修复缓存时削弱原文指令隔离。

DSH 的接管压缩与后台归档使用同一套规则。现有原文和已提交摘要保留。旧准备草稿因策略版本改变拒绝使用，随后根据原文重新准备。

```sh
dsh plugin --profile web add ./SuperLcm-0.5.29.tgz
```

其他 profile 替换名称。安装后重新加载或重启对应宿主；安装版本与当前运行版本分别核实。升级保持当前模型、分块、压缩比例和接管开关。

115 项回归及官方 CLI 在隔离 Mac 宿主上的安装升级测试通过。全部模型响应在本地模拟，未消耗付费模型额度。测试核对提示词字节布局、最后任务提醒及质量检查；实际缓存命中仍取决于供应商和模型。GitHub Actions 保持关闭。
