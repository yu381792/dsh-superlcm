# 0.5.34 升级说明

修复新版会话到 90% 时仍报“后台摘要尚未就绪”的衔接问题：原主请求只等 30 秒，而且等待整个固定范围的所有摘要批次；下一批开始生成时，已经完成的上一批也暂时不可用于提交。

现在后继批次生成期间保留已完成前缀，每批完成后检查它是否足以把上下文降到正常替换比例以下。满足条件就提交一次，未完成原文和当前输入仍保留；后继任务取消后的迟到输出拒绝发布。正常压力下仍等固定范围准备完，紧急压力才使用安全前缀。

等待使用用户现有摘要超时时间作为整次接入的总截止，多批不会重复续时。超时和取消仍保留请求，不能保证任意慢模型都能在截止内完成。

```sh
dsh plugin --profile paseo add ./SuperLcm-0.5.34.tgz --offline
```

原模型、比例及分块参数保持不变。正在运行的宿主必须重新加载才会生效；有后台任务时先等它结束。原文、旧摘要及持久草稿保留。测试使用真实 SDK 与本地假模型，付费摘要质量是另一个验证范围。
